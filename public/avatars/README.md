# Avatares de perfil

Coloca aquí las imágenes de personajes con estos nombres de archivo exactos (referenciados en `src/lib/avatars.ts`):

- `goku.png`
- `vegeta.png`
- `gohan.png`
- `piccolo.png`
- `bulma.png`
- `krillin.png`
- `trunks.png`
- `freezer.png`
- `cell.png`
- `buu.png`

Recomendado: PNG cuadrado (ej. 256x256), fondo transparente o sólido, mismo encuadre (rostro/torso) entre personajes para que se vean consistentes en el grid de selección y en el ícono de perfil del header.

Para agregar un personaje nuevo: sube el archivo aquí y añade una entrada en `AVATARS` en `src/lib/avatars.ts` (`id`, `name`, `src`).
